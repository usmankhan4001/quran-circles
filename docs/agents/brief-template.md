# Brief template

Every lane's brief has these parts, in this order.

```md
# Brief: <lane>

Lane: <name>
Work packages: <WP ids>
Wave: <n>
Priority: <P0 | P1 | P2>
Approval: <reviewer agent | human>

## Goal

<Two or three sentences. What exists when this lane is done.>

## You own

<Directories. Nothing else.>

## You must not touch

<Directories and files that belong to other lanes.>

## Read first

<Contracts, product docs and earlier briefs this lane depends on.>

## Deliverables

<A numbered list. Each item is small enough for one pull request.>

## Definition of done

<Checkable statements.>

## Commands that must pass

<The exact commands.>

## Decisions to respect

<Product decisions and constraints that apply here.>

## Stand-ins

<What to use if an outside item or another lane is not ready.>
```
