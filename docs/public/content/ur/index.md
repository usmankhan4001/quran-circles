# قرآن سرکلز کی دستاویزات

قرآن سرکلز پاکستان میں لوگوں کو قریب ترین قرآنی نشست تلاش کرنے، ایک ٹیپ میں اس میں شامل ہونے اور کبھی نہ چھوٹنے میں مدد دیتا ہے۔ منتظمین اپنا مقام یا حلقہ فون سے چلاتے ہیں۔ ایڈمن ویب کنسول سے شہر یا پورے ملک کی نگرانی کرتے ہیں۔

اپنی ضرورت کا صفحہ چنیں۔

- [رکن کی رہنما](member-guide.md): نشست تلاش کریں، شامل ہوں، یاد دہانیاں پائیں، قرآن پڑھیں، اپنا اکاؤنٹ سنبھالیں۔
- [منتظم کی رہنما](coordinator-guide.md): آج کی نشست چلائیں، حاضری لگائیں، اطلاع بھیجیں، وقت بدلیں، پوسٹر بنائیں۔
- [کنسول کی رہنما](console-guide.md): نشستیں، مقامات، منتظمین، برآمدات، ایک ساتھ درآمد اور آڈٹ لاگ۔
- [API کا جائزہ](api-overview.md): عوامی API کیسے استعمال کریں (انگریزی میں)۔
- [فنِ تعمیر](architecture.md) اور [تعیناتی](deployment.md): پلیٹ فارم کیسے جڑا ہے (انگریزی میں)۔
- [ERPNext انضمام](erpnext.md): ERPNext سائٹ سے رابطہ، اور پہلے کیا بنانا ہوگا (انگریزی میں)۔

## یہاں کیا شائع ہے اور کیا نہیں

| حصہ                              | شائع                                              | وجہ                                                                                         |
| -------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| رکن، منتظم اور کنسول کی رہنمائیں | ہاں                                               | یہ لوگوں کو پروڈکٹ استعمال کرنا سکھاتی ہیں۔                                                 |
| عوامی API کا حوالہ               | ہاں، معاہدے سے خودکار (ورژن {{CONTRACT_VERSION}}) | یہ صرف وہی بتاتا ہے جو زائر یا سائن اِن شدہ رکن پہلے ہی ایپ میں کر سکتا ہے۔                 |
| منتظمین کا API                   | نہیں، [وجہ دیکھیں](api-staff.md)                  | یہ دوسروں کے فون نمبروں تک پہنچتا ہے، رقم خرچ کرنے والے پیغام بھیجتا ہے اور رسائی بدلتا ہے۔ |
| فنِ تعمیر اور تعیناتی            | ہاں، عوام کے لیے محفوظ حد تک                      | میزبان کے نام، رازوں اور حملہ آور کے کام کی تفصیلات چھوڑ دی گئی ہیں۔                        |

## زبانیں اور رسائی

رہنمائیں انگریزی اور اردو میں ہیں۔ اردو متن اس وقت تک مسودہ ہے جب تک کوئی مقامی اردو بولنے والا نظرِ ثانی نہ کرے، اور ہر اردو صفحہ یہ بتاتا ہے۔ API، فنِ تعمیر اور انضمام کے صفحات صرف انگریزی میں ہیں۔

یہ صفحات ایپس کے اصولوں پر چلتے ہیں: چار سائز کا متن، اردو کے لیے دائیں سے بائیں ترتیب، روشن اور تاریک تھیم، کم از کم 48 پکسل کے بٹن، نظر آنے والا فوکس، چھوڑ کر آگے جانے کا لنک، اور جب سسٹم کم حرکت مانگے تو کوئی حرکت نہیں۔ تفصیل [رسائی اور زبانیں](accessibility.md) میں ہے۔
