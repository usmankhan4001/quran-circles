# Decision records

Short, numbered records of real choices, so the next agent does not re-decide them.

File name: `NNNN-short-title.md`. Template:

```md
# NNNN: <title>

Status: proposed | accepted | superseded by NNNN
Date: <yyyy-mm-dd>
Lane: <who proposed it>

## Context

<What forced the choice, in two or three sentences.>

## Options

<Two or three options with one line each.>

## Decision

<What was chosen and why.>

## Consequences

<What gets easier, what gets harder, what to revisit.>
```

A decision that changes a contract also needs a contract change request.
