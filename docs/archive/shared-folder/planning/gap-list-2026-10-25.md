# Quran Circles: gap list (25 Oct 2026)

Built from the Quran Circles Audit, the 25 Oct test pass and a fresh read of `main` at `cbea1f4`.
Seat booking is out of scope here: it is being replaced by the join pledge in its own thread.

Legend: **Fix now** = clearly decided, I fix it here. **You decide** = needs your choice. **You do** = only you can do it.
