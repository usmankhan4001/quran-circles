# Support

| I need help with...                           | Where to go                                                                                                                                           |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| Using the app (joining a session, my account) | Email support@qurancircles.doraquran.pk, or read the [member guide](docs/public/content/en/member-guide.md)                                           |
| Coordinating a session or venue               | The [coordinator guide](docs/public/content/en/coordinator-guide.md)                                                                                  |
| Running or changing the code                  | [Getting started](docs/getting-started.md), then open a [work package or bug issue](https://github.com/usmankhan4001/quran-circles/issues/new/choose) |
| A security problem                            | [SECURITY.md](SECURITY.md). Do not open a public issue.                                                                                               |

Never send a sign-in code or a password to anyone, including by email to support.
